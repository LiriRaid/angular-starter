# Contributing to Starter Angular

Thanks for your interest. The project is in a **pre-alpha planning phase**, so the contribution process is intentionally light and will grow with the project.

## Current status

- Code contributions are not being accepted yet while the scope, architecture and licensing review are settled.
- Ideas, questions and feedback are welcome as GitHub issues once the repository is public.

## Conventions (draft)

- Code, comments, commit messages and documentation are written in **English**.
- Commits follow [Conventional Commits](https://www.conventionalcommits.org/) (`feat`, `fix`, `docs`, `chore`, ...).
- Generated applications must follow the official Angular conventions: standalone components, strict TypeScript, Signals and modern control flow.
- No business logic, secrets, private configuration or proprietary assets from third-party or employer projects may be added to this repository.
- By contributing you agree that your contribution is licensed under the project's [MIT License](LICENSE).

## Reporting security problems

Do not open a public issue. See [SECURITY.md](SECURITY.md).

## Code of conduct

Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).
